# 라이선스

wsPrism은 **Apache License 2.0**으로 배포합니다. 전문은 저장소의 [`LICENSE`](https://github.com/AsyncNomad/wsPrism/blob/main/LICENSE) 파일에 있습니다.

간단히 말해, 상용·비공개 제품을 포함해 wsPrism을 쓰고, 고치고, 배포할 수 있습니다. 조건은 라이선스와 저작권 고지를 유지하고, 파일을 크게 고쳤다면 그 사실을 밝히고, 프로젝트 이름을 내 제품을 보증하는 데 쓰지 않는 것입니다. 기여자의 명시적인 특허 허락도 포함돼 있습니다.

## 보증 없음

wsPrism은 어떤 보증도 없이 "있는 그대로" 제공됩니다. 아직 정식 보안 감사나 대규모 운영 검증을 거치지 않았고, Redis 클러스터는 실험적 기능입니다. 운영 환경에 쓰려 한다면 먼저 실제 부하로 시험하고, 보안 요구 사항에 맞는지 직접 검토하세요.
